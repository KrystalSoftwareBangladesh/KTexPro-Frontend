# CRM Dashboard

CRM Dashboard UI crafted with Shadcn and Vite.


## Run Locally

Clone the project

```bash
  git clone https://github.com/KrystalSoftwareBangladesh/KTexPro-Frontend.git
```

Go to the project directory

```bash
  cd KTexPro-Frontend
```

Install dependencies

```bash
  pnpm install
```

Start the server

```bash
  pnpm run dev
```
